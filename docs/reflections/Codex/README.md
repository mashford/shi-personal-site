# Codex 命令手册

这里按 Codex 桌面 App 菜单中的命令拆分文档。每个命令有独立的 Markdown 文件，方便单独阅读和更新。

## 怎么使用

在 Codex 输入框中输入 `/`，打开当前版本的命令菜单。命令是否出现会随客户端、账号、项目和权限变化。

菜单显示名称和实际命令名可能不同，例如：

| 菜单名称 | 命令 |
| --- | --- |
| Code review | `/review` |
| Compact | `/compact` |
| Fast | `/fast` |
| Feedback | `/feedback` |
| Fork chat | `/fork` |
| Goal | `/goal` |
| IDE context | `/ide-context` |
| MCP | `/mcp` |
| Model | `/model` |
| Plan mode | `/plan` |
| Reasoning | `/reasoning` |
| Status | `/status` |

## 说明

这些文档主要针对桌面 App 的命令菜单。CLI 和 IDE 扩展有自己的命令集合，不能把所有菜单项直接当作终端命令使用。

如果当前菜单和文档不一致，以实际菜单为准；公开文档也会随版本更新。

官方参考：[Slash commands](https://learn.chatgpt.com/docs/reference/slash-commands)、[Developer commands](https://learn.chatgpt.com/docs/developer-commands)。
