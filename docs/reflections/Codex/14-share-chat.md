# Share chat：分享当前聊天

菜单名称：`Share chat`
常见入口：命令菜单中的分享动作；部分环境支持 `/share`

## 它做什么

Share chat 会创建当前聊天的分享快照或分享链接，方便别人查看你的问题、背景和 Codex 的结果。

```text
/share
```

如果当前版本没有 `/share`，直接从命令菜单选择 `Share chat`。

## 分享前检查

不要把分享当成“只发最后一句回答”。聊天中可能包含：

- 本地绝对路径；
- 私有仓库名；
- 代码片段和业务逻辑；
- 终端输出；
- API 地址、错误日志或设计稿；
- 个人信息和内部链接。

分享前先确认内容范围和访问权限。对工作项目，优先使用团队允许的文档或代码评审系统。

## 适合分享的内容

- 可公开的学习过程；
- 已脱敏的错误排查；
- 通用的命令使用方式；
- 不包含密钥和私有代码的最终方案。

## 不适合直接分享的内容

- 生产凭证和 token；
- 未公开的客户数据；
- 私有仓库的完整代码；
- 含个人信息的诊断日志。

分享之后仍要把最终代码、测试结果和提交记录放在正式的项目渠道中；分享聊天不等于代码已经提交、部署或完成审查。

官方参考：[Commands](https://learn.chatgpt.com/docs/reference/commands)。
