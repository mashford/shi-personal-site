# Fast：速度优先的服务层

菜单名称：`Fast`
常用命令：`/fast`

## 它做什么

Fast 用于打开或关闭当前模型提供的 Fast 服务层。截图中显示的是 `1.5x speed, increased usage`，这是你当前账号或模型的界面说明；具体速度、额度和可用性会随模型与账号变化。

```text
/fast
```

通常再次执行会在开启和关闭之间切换。可用时，界面会显示当前状态。

## 适合使用的任务

- 简单的文件查询；
- 小范围文案或样式修改；
- 已经明确方案的机械性改动；
- 需要快速获得多个候选答案的探索。

## 不要只看速度的任务

- 跨文件架构重构；
- 复杂 Bug 定位；
- 视觉还原和截图比对；
- 生产部署和数据迁移；
- 需要多轮验证的长任务。

Fast 不是“更聪明的模式”，而是服务速度和使用量的取舍。它也不能弥补缺少上下文、设计证据或测试标准的问题。

## 建议

```text
先用 Fast 做信息收集
  ↓
确定方案后再实施
  ↓
复杂阶段关闭 Fast 或选择更高推理
  ↓
仍然运行完整验证
```

如果菜单中没有 `/fast`，说明当前模型或账号没有提供该服务层；不要手动修改配置来强行开启。
