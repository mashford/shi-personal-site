# Sketch：绘制草图输入

菜单名称：`Sketch`
菜单说明：`Draw a sketch`

## 它做什么

Sketch 是命令菜单中的草图输入工具，可以让你先画出一个结构、布局或视觉关系，再把草图作为当前任务的输入。

它适合表达文字不容易描述的内容，例如：

- 页面区块的大致位置；
- 组件之间的关系；
- 一个交互流程；
- 你希望 Codex 还原的布局层级。

## 使用建议

画完草图后，补充文字说明：

```text
这是页面的结构草图，不是最终视觉稿。
请根据它规划组件层级；颜色、字体和间距仍以项目中的设计稿为准。
如果无法确认某个尺寸，请先列出假设，不要自行确定。
```

如果草图用于视觉还原，最好同时提供：

- 原始设计稿或参考截图；
- 视口尺寸；
- 字体和图片资源；
- 需要保留的交互；
- “可推断”和“不可推断”的边界。

## 不要把草图当成完整规格

草图通常只能表达结构和关系，不能可靠表达：

- 精确像素值；
- 字体度量；
- 颜色和渐变；
- 动画节奏；
- 响应式断点；
- 无障碍语义。

这些信息缺失时，应要求 Codex 标记未知项，或者继续提供证据。

公开的 Codex 斜杠命令文档目前没有给出 `Sketch` 的完整命令语法，因此本文只解释截图中可确认的菜单行为，不假设它一定存在 `/sketch` 命令。

官方命令入口：[Slash commands](https://learn.chatgpt.com/docs/reference/slash-commands)。
